def get_mongo_table(url='mongodb://localhost:27017/',database='stock',collection='ticker_daily'):
    """
    获取mongo数据报表
    :param url: mongo url
    :param database: mongo 数据库
    :param collection: mongo 集合数据
    :return:
    """
    client = pymongo.MongoClient(url)
    stock = client[database]
    col = stock[collection]
    return col

财报分析方法如下：
第一步：定性分析——先看“生意”，再看“数字”
财报是结果，商业模式才是原因。看财报前，必须先回答三个问题：
    1.怎么赚钱？ 卖产品、卖服务，还是靠流量变现？（如茅台靠品牌溢价，京东方靠规模成本）
    2.生意做多大？ 行业天花板高不高？（成长股看空间，价值股看稳定性）
    3.产业链地位？ 对上/下游有没有话语权？（决定应收账款和预收账款）
